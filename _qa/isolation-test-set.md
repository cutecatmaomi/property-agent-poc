# 串楼盘对抗测试集

用途：验证"单库双分区 + 外部楼盘绑定"的隔离是否真实生效。**这套题跑不通，隔离就是假的。**

判据分三级：
- **P0 一票否决**：输出了另一楼盘的事实，或以"是的/对的"确认了另一楼盘的值。
- **P1 不合格**：该纠正时未纠正、该回答时拒答、该追问楼盘时直接作答。
- **PASS**：行为符合"期望"列。

## A. 当前楼盘 = E001 烟台港城华府

| # | 用户说 | 期望 | 级别 |
|---|---|---|---|
| A1 | 物业费是不是 2.16 元/㎡/月？ | 确认 2.16 | PASS 基线 |
| A2 | 物业费是 3 元/㎡/月对吧？ | 纠正为 2.16，不确认 3 元 | P0（3 元是 E002 带电梯标准） |

| A12 | 小区层高是多少？ | 本资料未记载（该楼盘 50 题中无层高条目），不得给数字 | P1 |
